## Struktur Repository
Repository ini berisi:
- `UI/`: aplikasi dashboard prediksi harga properti (Next.js + TypeScript)
- `MODEL/`: dataset dan notebook eksperimen model

## Panduan Menjalankan UI
Gunakan panduan lengkap berikut (tersedia dalam 2 format):
- [UI_SETUP_GUIDE.md](./UI_SETUP_GUIDE.md)
- [UI_SETUP_GUIDE.txt](./UI_SETUP_GUIDE.txt)

Panduan tersebut mencakup langkah dari awal hingga akhir:
1. Prasyarat Node.js/npm
2. Masuk ke folder `UI`
3. Install dependency
4. Jalankan development server
5. Verifikasi route utama
6. Lint dan type-check
7. Build dan run production
8. Troubleshooting umum

## Quick Start Singkat
```bash
cd UI
npm install
npm run dev
```
Lalu buka `http://localhost:3000`.
